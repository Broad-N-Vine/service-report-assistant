## Day 51 tasks

### 1. Confirm sitemap and robots access

Open:

- /sitemap.xml
- /robots.txt

Confirm:

- sitemap.xml loads.
- robots.txt loads.
- sitemap excludes /api/.
- sitemap excludes thank-you.html.
- robots.txt disallows /api/.
- robots.txt disallows /thank-you.html.
- robots.txt references sitemap.xml.

### 2. Submit sitemap for indexing

Submit sitemap URL to search tools when available:

https://service-report-assistant.pages.dev/sitemap.xml

Track whether submission succeeds.

### 3. Record baseline index status

Check whether Google already knows the site.

Search:

site:service-report-assistant.pages.dev

Record:

- Is the homepage indexed?
- Are any tool pages indexed?
- Are any guide pages indexed?
- Are any outdated pages indexed?
- Are any unwanted URLs indexed?

### 4. Set up or confirm analytics baseline

Confirm what tracking is currently available.

Minimum metrics to track weekly:

- Total site visits
- Top landing pages
- AI tool page visits
- AI tool submissions
- Email signups
- Jobber affiliate clicks
- QuickBooks affiliate clicks
- Search impressions
- Search clicks
- Top queries
- Indexed pages

- Invoice tool uses
- Follow-up tool uses
- Maintenance pitch tool uses
- Estimate tool uses
