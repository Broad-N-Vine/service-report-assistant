# Day 12 — Monetization and Tracker Reset

## Goal

Turn the current HVAC AI Helper site from a collection of pages into a clearer traffic, email, and monetization system.

The site should not depend on instant revenue. The goal is to make sure every page has a clear purpose inside the system:

Search traffic -> helpful page -> free tool -> email capture -> follow-up emails -> recommended resource or future paid product.

## Day 12 Checklist

### 1. Tracker Reset

For each page, confirm:
- Page title
- Niche
- Tool
- Keyword
- Page slug
- Page type
- Priority
- Status
- Published link
- Email CTA
- Offer link
- Notes
- AI capability status
- Sitemap status
- Primary monetization path

---

### 2. Link Review

For each new page, confirm:
- Header navigation works
- Main CTA goes to the correct tool
- Related links work
- Footer links work
- Jobber link works
- QuickBooks link works
- MailerLite form appears

---

### 3. Sitemap Review

Confirm sitemap includes every public page.

Do not include:
- Template files inside /templates/
- Planning files inside /planning/
- Draft files
- Internal notes

---

### 4. Monetization Review

For each page, confirm:
- Affiliate disclosure appears before affiliate links
- Jobber and QuickBooks links use correct attributes
- HVAC Paperwork Starter Kit is marked Coming Soon
- Resource section does not overpromise
- Page does not sound like it only exists to sell

---

### 5. Email Capture Review

For each page, confirm:
- Email capture appears before or near the bottom
- Visitor understands what they get
- Unsubscribe language is present
- “We do not sell your email” language is present
- Human review language is present

---

### 6. AI Capability Review

Current status:
- Demo / frontend helper
- Not connected to live AI backend yet

Important:
- Do not claim the tools are fully AI-powered until backend is connected.
- Keep language careful when describing the current tool experience.
- Future upgrade can connect backend safely without exposing API keys.

---

## Day 12 Outcome

By the end of Day 12, the site should have:

- Cleaner tracker control
- Clear monetization path per page
- Updated sitemap confidence
- Better internal link confidence
- Clear next step for either:
  1. Email sequence setup
  2. Real AI backend setup
  3. First paid template product
  4. More SEO pages
